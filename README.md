# Model Categorize

フォルダ内の 3D モデルファイルを一覧・プレビューしながら、チームで決めたラベルを手動で付けていく Web アプリです（Next.js / Vercel 向け）。

## できること

- **フォルダ選択**: ブラウザでフォルダを選ぶと、サブフォルダも含めて 3D モデルを一覧表示
  - 対応形式: `.stl` `.obj` `.fbx` `.gltf` `.glb` `.ply` `.3mf` `.dae` `.3dm`（Rhino）
  - ファイルはアップロードされません。すべてブラウザ内で処理します
- **3D プレビュー**: 回転・ズーム、頂点数・ポリゴン数・サイズ表示
  - **部品**: 部品（名前ごと。Rhino はレイヤーごと）の表示・非表示、「この部品のみ」表示
  - **色分け**: 部品ごとに色を分けて表示
  - **断面**: X / Y / Z 方向に切って中を見る（スライダーで位置を調整）
  - **計測**: モデル上の 2 点をクリックして距離を表示（単位はファイルのまま）
  - **ワイヤーフレーム**表示
  - glTF の `.bin` やテクスチャ、OBJ の `.mtl` も同じフォルダから自動で読み込み
  - Rhino の曲面（NURBS）は、ファイルに保存された表示用メッシュで表示します。表示メッシュなしで保存されたファイルは形状が表示されません（ラベル付けはできます）
- **ラベル管理**: 自由に作成・名前変更・色変更・削除
- **ラベル付け**: 1 ファイルずつ、またはチェックした複数ファイルにまとめて付け外し
- **手動未操作の印**: 一度も手動でラベル操作していないファイルには「未操作」の印が付きます（自動ラベル付けの結果と区別するため）
  - ラベルを付け外しすると自動で「手動操作済み」になります
  - ラベルを変えずに「確認済みにする」、間違えたときは「未操作に戻す」こともできます
- **レシピからの自動ラベル付け**: フォルダを開くと、`recipes/` にある同じ名前の JSON の `ops` を、そのモデルのラベルとして自動で付けます
  - 例: `models/foo.stl` ↔ `recipes/foo.json`（サブフォルダも同じ構成で対応。見つからなければ `recipes/` 以下の同じ名前のファイル）
  - `ops` の要素が文字列ならそのまま、オブジェクトなら `op` / `type` / `name` / `kind` / `operation` の値をラベル名にします
  - **手動未操作のファイルだけ**が対象です。人が操作したファイルは変更しません
  - 手動未操作のファイルは、開くたびにレシピの内容に合わせて更新されます（レシピを直したら、フォルダを開き直すと反映）
- **絞り込み**: ラベルで「すべて含む」「どれか含む」、ラベルの除外、未ラベルのみ、手動未操作のみ（または除外）、ファイル名検索
- **名前のコピー**: 一覧の各行の ⧉ ボタンでファイル名をコピー。右下の「名前をコピー」「パスをコピー」は、チェックした複数ファイルをまとめて（1 行に 1 件）コピー
- **出力**: CSV（Excel で開ける）/ JSON 出力、JSON 取り込み

### キーボード・マウス操作

| キー | 動作 |
|---|---|
| ↑ ↓ / j k | ファイルを移動 |
| 1〜9 | ラベルの付け外し（ラベル一覧の上から順） |
| Space | チェックの切り替え |
| ドラッグ | 一覧の上をドラッグして範囲をまとめてチェック（チェック済みの行から始めると外す） |
| Shift + クリック | 前にクリックした行からの範囲をチェック |
| Ctrl / ⌘ + クリック | その行のチェックを切り替え |

## 保存先

ラベルは**選んだフォルダの中の `labels.json`** に自動で保存されます（Chrome / Edge）。

```json
{
  "labels": [
    {"name":"キャラクター","color":"#e5484d"},
    {"name":"小物","color":"#f76b15"}
  ],
  "assignments": {
    "chars/hero.stl": ["キャラクター"],
    "props/box.obj": ["小物"]
  },
  "manual": [
    "chars/hero.stl"
  ]
}
```

- `manual` は、人が一度でも手動でラベル操作（または確認済みに）したファイルです。ここに無いファイルが「手動未操作」です
- `manual` が無い古い `labels.json` は、ラベルが付いているファイルをすべて手動操作済みとして扱います

- パスはフォルダからの相対パスなので、フォルダごとコピー・移動してもラベルはそのまま使えます
- 共有ドライブ上のフォルダなら、チームで同じ `labels.json` を使えます（保存のたびに最新のファイルを読み直してから書き込み、画面に戻った時にも読み直します）
- Firefox / Safari はフォルダへの書き込みに対応していないため、ブラウザ内に保存します（「JSON出力」で `labels.json` を書き出せます）

## ローカルで動かす

```bash
npm install
npm run dev
# http://localhost:3000
```

## Vercel へのデプロイ

Vercel でこのリポジトリを Import するだけです（設定はデフォルトのままで OK。サーバー側の保存は使いません）。

## 構成

```
app/page.tsx               画面
components/
  App.tsx                  メイン UI
  ModelViewer.tsx          three.js による 3D プレビュー
lib/
  models.ts                3D ファイルの読み込み
  folder.ts                フォルダを開く / labels.json への保存
  label-data.ts            ラベルデータの操作（追加・名前変更・削除・付け外し）
  recipes.ts               recipes/*.json の ops からの自動ラベル付け
scripts/
  copy-rhino3dm.mjs        .3dm 読み込み用の rhino3dm をビルド時に public/ へコピー
```
